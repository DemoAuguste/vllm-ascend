# SAGE 替换 PCDVQ 可行性分析报告

- 日期：2026-10-16
- 论文：*SAGE: Pushing 2-Bit Vector-Quantized LLMs toward Real-World Usability*（arXiv:2610.14745v1, SJTU）
- 官方实现：https://github.com/Zincwolf/sage （GPL-3.0，Linux + NVIDIA + CUDA 12.8）
- 目标模型：Qwen3.8-27B（`Qwen3_5ForConditionalGeneration`，64 层 hybrid：48×linear_attention + 16×full_attention，hidden 5120，VLM）
- 任务目标：**精度损失 < 0.5% 前提下实现更低 bit 量化**
- 结论先行：**SAGE 可替代 PCDVQ 作为混合精度方案的"低位档算子"，且明显更优；但 SAGE 不是 2–8bit 通用位宽量化器（本质是 ≤3bit 极低位方法，工作点约 2.0–2.5 bpw）；与 SLQ 接口正交、可组合，且能修复原方案"低位档不可用"的核心缺陷。**

---

## 1. 结论摘要

| 问题 | 结论 |
|---|---|
| **能否替换 PCDVQ？** | ✅ 能，且更优。SAGE 与 PCDVQ 同属"球坐标解耦 VQ"谱系，但补上了 PCDVQ 的致命短板（无误差补偿），并叠加激活加权（ESG）与逐矩阵自适应位分配（ABS）。 |
| **是否支持 2bit–8bit 任意 bit？** | ❌ 不支持。SAGE 本质是 ≤3bit 的极低位 VQ 方法，可用工作点约 **2.0–2.5 bpw**（论文仅验证 2.00/2.25）。高位宽下方向码本规模指数爆炸，且与其设计目标冲突。 |
| **与 SLQ 结合可行性？** | ✅ 可行，且优于原"PCDVQ+SLQ"方案。接口正交、bpp 可解析、敏感度黑盒兼容；SAGE 恰好补上原方案中最先崩掉的"低位档算子"环节。 |

**修订方向**：原方案中"低位档算子"由 PCDVQ 换成 **SAGE**，高位档仍用 **GPTQ-INT**，继续以 **SLQ 敏感度 + ILP** 做跨组混合精度分配。

---

## 2. SAGE 方法要点

SAGE = **S**plit **A**daptation and **G**rouping by **E**nergy，权重-only 的极低位 VQ 方法。

### 2.1 球坐标 VQ（Spherical VQ，承自 SPHQuant）

把权重矩阵每行沿输入维切成 `v=8` 的子向量 `w`，分解为三部分：

- **符号** `s = sign(w)`：**显式存储**，1 bit/权重（共 v=8 bit）
- **半径** `r = ‖w‖₂`：标量量化，`V` bit（每 `G=128` 个权重共享一个均匀网格 `r̂ = µg + qδg`）
- **非负单位方向** `d = |w|/r`：码本查表索引，`log₂K` bit

重建：`ŵ = r̂ · (s ⊙ c_z)`。位预算与 BPW：

```
B = v + log₂K + V                    (每 8 个权重)
BPW = B / v = 1 + (log₂K + V) / 8
```

基线 `(K,V)=(64,4)` → 18 bit / 8 权重 → **2.25 bpw**（论文主工作点）。

### 2.2 ESG（Energy-Stratified Grouping，能量分层分组）

- 用校准激活估计通道能量 `e_c = E[x_c²]`；
- 按能量降序把 `d_in` 个通道分成 `v=8` 个 tier，每个子向量从各 tier 各取一路（交错分组），使**每个子向量都跨越多个能量层级**；
- 用**激活加权球面 k-means** 拟合码本，权重 `ωᵢ ∝ eᵢ^0.75`（归一化到单位均值），让加权拟合优先保护高能敏感通道；
- 推理时对输入激活做对应置换（置换融入图编译，避免每次重复 gather）。

动机：等能量通道上 `ω=1` 退化为普通欧氏重建；交错分组使子向量内能量差异最大，加权拟合得以发挥作用。论文 Fig.3 显示误差削减主要来自最高能量的 10% 通道。

### 2.3 ABS（Adaptive Bit Split，自适应位分配）

在**固定 18 bit 预算**下，候选切分 `F = {(64,4), (128,3), (256,2)}`（`log₂K+V=10` 恒定），**逐矩阵**选激活加权重建误差最小者：

```
E_W(K,V) = Σ_c e_c ‖W_{:,c} − Ŵ_{:,c}‖² / Σ_c e_c ‖W_{:,c}‖²
(K*, V*) = argmin_{(K,V)∈F} E_W(K,V)
```

三种候选载荷相同，故可逐矩阵独立选择而保持总预算不变。切分在初始化后固定。

### 2.4 标定与 blockwise 优化

- **校准数据**：目标模型**自采样**——用全精度模型 greedy 生成响应（跨数学/代码/推理/指令/工具/通用对话 6 域），拼成 2048-token 定长序列，1920 train + 128 val。校准集越大越好（Fig.4b：512→5376 序列，平均分 70.22→74.22）。
- **blockwise 优化**：承自 SPHQuant/ParoQuant。按块序贯、以全精度块输出为目标，学生输入用**前序量化块**的输出（逐层误差补偿）；Adam 20 epoch、bs 16、lr 1e-3，只更新连续半径与码本角度（符号、方向索引、置换、切分固定），STE 过半径 rounding。

### 2.5 结果与 kernel

- 2.25 bpw 下 5 模型全部 SOTA，超越 SPHQuant **4.05–16.24 分**，保留 BF16 平均分 **78.9%–95.3%**（Qwen3-30B-A3B 最高 95.3%）。
- 评测覆盖 MMLU-Redux / GSM8K / MATH-500 / IFEval / HumanEval+ / BFCL-v3（知识/数学/代码/指令/工具）。
- 已含自研 CUDA kernel（16-bit 主字 + 2 辅助位打包），端到端最高 2.55× 加速。
- **架构先例**：Qwen3.5-4B-Thinking（hybrid linear+full attention，thinking 模式）、Qwen3-30B-A3B（MoE）、多模态 checkpoint 语言骨干——与 Qwen3.8-27B 高度对口。

## 3. 为什么 SAGE 能替代 PCDVQ（且更好）

两者同源（均为"方向 + 幅值/半径"的形状-增益分解），SAGE 逐条补强：

| 维度 | PCDVQ（当前实验 `experiment/PCDVQ-k3`） | SAGE | 影响 |
|---|---|---|---|
| 符号处理 | 极坐标隐式编码，论文 Eq.6 丢符号（实验已修正为 atan2 双射） | **显式存符号 bit** | 消除一类还原歧义/缺陷 |
| 方向码本 | 固定 **E8 格 + 贪心 FPS**（论文存在位算术矛盾、E8 池未定义、未单位化等缺陷） | **可学习**（激活加权球面 k-means） | 免去 E8 枚举难题，码本贴合真实分布 |
| 数据感知 | **模型无关、零训练**（全模型共享码本） | **激活感知**（ESG 通道能量 + 逐矩阵码本） | 保护敏感通道 |
| 位分配 | 固定切分（a=14~16, b=2） | **逐矩阵 ABS**（同预算三选一） | 适配不同权重矩阵 |
| **误差补偿** | **无**（纯贪心查表 fake-quant） | **有**：blockwise 优化（20 epoch，学生输入用前序量化块） | **最关键差异** |
| 官方实现 | 非官方半成品 notebook（5 处缺陷，未跑通端到端） | 官方仓库，含 CUDA kernel | 可复现性显著更高 |

### 3.1 与实验失败根因的直接对应（核心论据）

当前实验记录（`progress.md` 阶段 4）：PCDVQ `a=14`（2.0 bpw）**纯 fake-quant**使 WikiText-2 基线 PPL 从 **20.04 → 360702**（崩溃），逐层相对 Frobenius 误差恒定 ~0.314；根因明确为"**无 QuIP# 式误差补偿、无微调**时 31% 权重误差逐层累积"。

SAGE 的 **blockwise 优化正是这一环误差补偿**（与 SPHQuant/GPTQ 同类机制），是让极低位 VQ 真正可用的关键。PCDVQ 论文的 2.125bit 好结果本身也依赖 QuIP# 式块优化/微调——SAGE 将其**内建**。**这是"SAGE 替换 PCDVQ"最有力的理由。**

### 3.2 注意事项

SAGE 的 2.25bpw 单档仍有明显缺口（Qwen3-4B 上 HumanEval+ 差 BF16 22.56 分、MATH-500 差 15 分，平均保留仅 ~88%）。因此**仍必须靠混合精度把敏感组放到高位**，SAGE 只承担最不敏感的组——与原方案 D1 定位一致。

## 4. 是否支持 2bit–8bit 任意 bit？—— 不支持

**数学上**：`BPW = 1 + (log₂K+V)/8`，`log₂K、V` 取整数时可在 1/8 网格上任取（2.0 / 2.125 / 2.25 / … / 3.0 / …）。

**工程上不可行**，三条硬约束：

### 4.1 方向码本指数爆炸

`log₂K = 8·BPW − 8 − V`，位宽每 +1，码本规模 ×256：

| 目标 BPW | log₂K+V | 典型 (K,V) | 码本规模 | 评价 |
|---|---|---|---|---|
| 2.00 | 8 | (64,2) / (32,3) | ≤64 | 可行 |
| 2.125 | 9 | (64,3) | 64 | 可行 |
| **2.25** | 10 | (64,4)/(128,3)/(256,2) | 64–256 | **论文工作点** |
| 2.50 | 12 | (512,2)/(256,4) | 512 | 边界 |
| 3.00 | 16 | (4096,4) | 4096×8 | 共享内存放不下、解码退化 |
| 4.00 | 24 | ~2²⁰ | ~100 万码字 | 不可行 |
| 8.00 | 56 | 2⁵² | 天文数字 | 不可行 |

SAGE 依赖码本常驻 shared memory（K=64 时约 1 KiB）以"查表 + 符号翻转 + 一次乘法"完成解码；K 增大后该路径失效。

### 4.2 代码实现被写死

官方配置暴露的位相关旋钮只有：`adaptive_bits`（在三种切分间选，均为 2.25bpw）与 `codebook_bits: 6`（非自适应模式下复现 SPHQuant 64/4）；**没有任意位宽参数**。球面 k-means 的 `sample_size: 65536` 意味着 `log₂K ≤ 16`（样本少于码字数无意义），实际把 BPW 上限压到 ~3 出头。

### 4.3 设计目标冲突

论文明确面向 "below 3 bits"。≥4bit 时标量 INT4（GPTQ/AWQ）已近无损、kernel 成熟（vllm-ascend 有 W4A16 路径），VQ 收益消失。符号固定 1 bit/权重、`v=8` 的分解方式本身也是为极低位设计的。

**结论**：SAGE 提供的是**一族低位宽工作点（≈2.0–2.5 bpw，勉强到 ~3bpw）**，不是 2–8bit 的通用位宽量化器，**也不能充当高位档算子**；高位档仍需 GPTQ-INT。

## 5. 与 SLQ 结合的可行性

### 5.1 SLQ 对量化算子的硬要求（对齐 `feasibility.md` §3 Q1）

| 要求 | SAGE 满足性 | 说明 |
|---|---|---|
| ① 给定层+位宽产出 fake-quant 权重 | ✅ | 官方默认导出即**密集 QDQ 权重**（HF 可加载），与 SLQ `WeightStore` 完全对接 |
| ② 组级热替换做 Shapley 前向 | ✅ | SAGE 是**逐矩阵**量化（比 SLQ 组更细），"某组选 SAGE-2.25"即该组所有矩阵用同一 SAGE 配置 |
| ③ bpp 可解析计算 | ✅（须含元数据） | 论文 Eq.15：`BPW = B/v + 2b_g/G + K·v·b_c/N`。**必须额外计入**网格参数 +0.25bpw@G=128（→2.50bpw）、逐矩阵码本、ESG 置换表，否则 SLQ 预算约束失真 |
| Shapley / 线性敏感度 | ✅ | 敏感度是**度量驱动的黑盒**（只看组换档前后 NLL/KL/EAR 变化），与量化器类型无关 |

### 5.2 关键协同点

1. **补上"低位档可用性"缺口**：原方案最大风险是低位档 `{2.0, 2.125}` 不可用（PCDVQ 崩溃），等于混合精度池里没有可用的 2bit 候选。SAGE 的误差补偿让 **2.0–2.25bpw 成为真正可用的最低档**，把 ILP 可行域重新打通。
2. **粒度互补**：SAGE 做**矩阵内**通道分组（ESG）+ 方向/半径切分（ABS）；SLQ 做**组间**位宽分配。二者不重叠，可叠加。
3. **候选池拼接**：把 SAGE 的 `{2.0, 2.125, 2.25, (2.5)}` 作为 SLQ 候选集**低位段**算子，`{3,4,6,8}` 仍由 GPTQ-INT 承担。

### 5.3 修订后的组合方案（SAGE + SLQ）

```
校准数据 ─► 阶段A 逐层算子池
             · GPTQ 非对称 INT g128：{3,4,6,8} bit          （高敏感组）
             · SAGE 球面 VQ：(K,V)∈{(64,2),(64,3),(64,4),(128,3),(256,2)}
                              → 2.0 / 2.125 / 2.25 bpw       （低敏感组，含 blockwise 误差补偿）
                    ▼
           阶段B SLQ 敏感度（Shapley / 线性 α）
                    ▼
           阶段C ILP 混合精度分配 + SLQ-TL 单点标定
                    ▼
           阶段D 拼装 fake-quant checkpoint → PPL / zero-shot 评测
```

## 7. 建议的下一步

1. **0.6B 冒烟**：实现 SAGE 量化器（ESG 分组 + 球面 k-means + ABS 三切分 + blockwise 优化），在 Qwen3-0.6B 上跑 `{2.0, 2.125, 2.25} bpw` 的 PPL 曲线——**关键验证点：有 blockwise 误差补偿后，2.25bpw 是否不再崩溃**。这是替换决策的实证底线。
2. **逐层对比**：SAGE-2.25 vs GPTQ-INT-3 在各组（尤其 linear_attn）上的重建/输出误差，确定低位档与高位档的分工边界。
3. 通过后进入原阶段 5：GPTQ-INT 算子 + SLQ 敏感度 + ILP，把 SAGE 档接入候选池。
4. 27B 全量：标定激活 → 敏感度 → ILP → fake-quant checkpoint → zero-shot 相对损失 ≤0.5% 评测。

---

## 8. 结论

SAGE 是比 PCDVQ 更成熟、更贴合本任务（hybrid + VLM、极低位、有官方实现）的低位宽 VQ 算子，**应替换 PCDVQ 作为混合精度方案的"低位档"**；但它**不是 2–8bit 通用量化器**，高位档必须继续依赖 GPTQ-INT；与 SLQ 的接口正交、可组合，且能修复原方案"低位档不可用"的核心缺陷。

**判定：替换可行且推荐，建议按第 7 节以 0.6B 冒烟先行验证。**
